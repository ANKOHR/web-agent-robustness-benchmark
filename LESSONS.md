# Lessons for KOML

The domain requires paired trial semantics before it requires sophisticated metrics. A changed interface failure is a regression only if the baseline passed under the same task success criterion. Baseline failures, improvements, unlabelled observations, and unchanged controls must remain visible in totals.

Validated by local synthetic evidence: explicit boolean outcomes and a deterministic pure evaluator can reconcile every planted count and regression ID. Corrupting one observed outcome changes counts and introduces a false negative; corrupting one label introduces a false positive. These tests validate computation rather than a static report. The broader assumption that this helps real users remains untested until the two-week real-use window.

Operating rule for future builds: define the measured unit and independent ground truth before building reports. Never convert fixture accuracy into a claim about real agents, and never treat missing labels as successful validation. Keep the post-use verdict pending until there is actual usage evidence.
